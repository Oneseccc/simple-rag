# Enterprise Features

## Overview

Anthropic offers enterprise-grade features for organizations that require advanced security, compliance, and administrative controls when using Claude. These features are available through the Anthropic Console and API.

## Single Sign-On (SSO)

Enterprise accounts support SAML-based SSO integration with identity providers such as Okta, Azure AD, and Google Workspace. SSO enables centralized access management and enforces your organization's authentication policies.

## Role-Based Access Control

Manage team permissions with fine-grained roles:

- **Admin**: Full access to billing, settings, and API keys.
- **Developer**: Can create and manage API keys and view usage.
- **Viewer**: Read-only access to usage dashboards and logs.

## Usage Monitoring and Audit Logs

The enterprise dashboard provides detailed usage analytics:

- Per-model token consumption over time
- Per-user and per-API-key breakdowns
- Cost tracking and budget alerts
- Audit logs of all API key creation, deletion, and permission changes

## Data Privacy and Security

- **Data retention**: Anthropic does not use API inputs or outputs to train models. Enterprise customers can configure custom data retention periods.
- **Encryption**: All data is encrypted in transit (TLS 1.2+) and at rest (AES-256).
- **SOC 2 Type II**: Anthropic maintains SOC 2 Type II compliance.
- **HIPAA**: Available for qualifying enterprise accounts handling protected health information.

## Custom Rate Limits

Enterprise and Scale tier customers can negotiate custom rate limits based on their usage patterns. Contact the Anthropic sales team to discuss higher throughput requirements.

## Dedicated Support

Enterprise accounts receive:

- Dedicated account manager
- Priority technical support with SLA guarantees
- Access to early features and beta programs
- Onboarding assistance and prompt engineering guidance
